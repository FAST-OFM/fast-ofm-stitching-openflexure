# Upstream relationship

This worker depends on `openflexure-stitching==0.3.1` and extends its public
image-set, correlation, optimisation and geometry interfaces. The accelerated
correlation loop and nearest-centre ownership implementation are treated as
LGPL-derived modifications. The source for these modifications is included
here; the unmodified dependency is pinned and remains available from the
[`openflexure-stitching` project](https://gitlab.com/openflexure/openflexure-stitching).

Fast OFM is an independent modified research project. This repository does not
imply endorsement by the OpenFlexure project.
